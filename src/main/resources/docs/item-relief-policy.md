# 단풍이야기 아이템 사용 실수 구제 정책

시행일: 2026-06-01
적용 범위: 사용 전/후 결과를 선택할 수 있는 일부 강화·재설정 아이템

## 1장 총칙

### 제1조 (목적)

이 정책은 사용 전/후 결과 중 하나를 직접 선택하는 방식의 아이템에서, 이용자가 실수로
잘못된 선택을 한 경우의 복구 기준을 정하여 신속하고 일관되게 처리하는 것을 목적으로
한다.

### 제2조 (적용 대상의 성격)

1. 본 정책은 아이템 사용 결과 자체가 마음에 들지 않는 경우(원하는 옵션이 나오지 않은
   경우 등)에는 적용되지 않는다. 이는 정상적인 확률 결과이며, 재화 회수 없이 반복
   사용이 가능한 콘텐츠의 본질적인 특성이다.
2. 본 정책이 적용되는 경우는 오직 "전/후 중 어느 쪽을 적용할지 선택하는 절차"에서
   이용자가 의도와 다른 버튼을 누르거나 클릭을 잘못하여, 원래 유지하려던 상태가
   아닌 다른 상태로 확정되어 버린 경우에 한정한다.

## 2장 적용 대상 아이템

### 제3조 (전/후 선택이 가능해 적용 대상이 되는 아이템)

아래 각 호의 아이템은 사용 시 결과를 적용할지 여부(전/후)를 이용자가 직접 선택하는
구조를 가지므로, 오조작으로 인한 복구 신청 대상이 된다.

1. 잠재능력·에디셔널 잠재능력 재설정 큐브 중 사용 전후 비교·선택이 가능한 종류
   (예: 블랙 큐브 — 등급업 여부와 무관하게 재설정 결과를 전/후 비교해 선택하는 큐브류)
2. 추가옵션 재설정 계열 아이템(환생의 불꽃류 — 등급에 따라 명칭이 다양하며, 카르마가
   붙은 교환 불가 전용 버전을 포함) — 재설정 결과를 적용할지 기존 상태를 유지할지
   선택하는 모든 종류
3. 장비 강화 주문서 사용 시, 실패·성공 결과를 적용 전 상태로 되돌릴 수 있는 보조
   아이템(예: 리턴형 주문서)을 함께 사용한 경우의 전/후 선택

### 제4조 (전/후 선택이 불가능해 적용 대상에서 제외되는 재화)

다음 각 호는 결과가 사용 즉시 확정되어 이용자가 선택할 수 있는 "전/후" 단계 자체가
존재하지 않으므로, 본 정책의 적용 대상이 아니다.

1. 결과 확인 없이 사용 즉시 적용되는 강화 방식(예: 메소를 직접 소모하는 단계형
   강화 — 소위 "스타포스" 방식)
2. 사용 시 결과가 즉시 확정되고 전/후 비교·선택 기능이 별도로 제공되지 않는
   잠재능력 재설정 방식(예: 재설정 즉시 옵션이 바로 적용되는 방식)
3. 즉시 소비되어 효과가 바로 적용되는 소모성 아이템(물약, 즉시 회복형 재화 등)
4. 거래·양도 등을 통해 최종 결과만 확인 가능한 재화

### 제5조 (판단 기준의 근거)

전/후 선택이 가능한 아이템은 그 선택 과정에서 사람이 실수할 여지(오조작)가 시스템
구조적으로 존재한다. 반면 제4조의 재화는 애초에 선택 단계가 없어 "잘못 선택"이라는
사건 자체가 성립할 수 없으므로, 그 결과가 마음에 들지 않는다는 사유는 오조작이 아니라
정상적인 확률 결과에 대한 불만으로 처리한다.

## 3장 복구 신청과 처리

### 제6조 (복구 횟수 제한)

1. 이용자 1인당 연 2회에 한하여 오조작 복구를 신청할 수 있다.
2. 복구 횟수는 매년 1월 1일 0시를 기준으로 초기화된다.
3. 동일 계정에 여러 캐릭터가 있는 경우, 복구 횟수는 계정 단위로 합산하여 관리한다.

### 제7조 (신청 방법)

1. 이용자는 오조작이 발생한 즉시 해당 아이템을 더 이상 사용하지 않고, 고객센터
   1:1 문의를 통해 발생 일시, 캐릭터명, 사용한 아이템명, 원하던 선택과 실제로
   적용된 결과를 구체적으로 기재하여 신청한다.
2. 오조작 발생 시점으로부터 상당한 시간이 경과한 뒤 신청하는 경우, 사실관계 확인이
   어려워 복구가 제한될 수 있다.
3. 같은 아이템을 복구 신청 이후에도 반복해서 사용한 경우, 원래 상태 확인이
   불가능해져 복구가 거부될 수 있다.

### 제8조 (처리 절차)

1. 회사는 신청 내용과 서버 로그를 대조하여 실제로 전/후 선택 단계에서 오조작이
   발생했는지 확인한다.
2. 확인이 완료되면 해당 아이템을 오조작 이전 상태로 복구하고, 복구 횟수 1회를
   차감한다.
3. 처리 기한은 접수일로부터 5영업일 이내를 원칙으로 하되, 로그 확인에 추가 시간이
   필요한 경우 이용자에게 사전 안내한다.

### 제9조 (복구가 제한되는 경우)

다음 각 호에 해당하는 경우 복구 신청이 거부될 수 있다.

1. 연간 복구 횟수를 이미 모두 사용한 경우
2. 서버 로그상 전/후 선택 단계에서의 오조작이 확인되지 않는 경우
3. 제4조에 해당하여 원천적으로 전/후 선택 자체가 없었던 아이템에 대한 신청인 경우
4. 동일한 사유로 반복적으로 신청하여 제도를 남용하는 것으로 판단되는 경우

## 4장 기타

### 제10조 (다른 정책과의 관계)

본 정책에 따른 복구는 계정 운영 정책상 재화 회수와는 무관하며, 정상적으로 취득한
재화에 대해서만 적용한다. 비정상적인 방법으로 취득한 재화에 사용한 경우는 계정 운영
정책의 회수 절차를 우선 적용한다.

### 제11조 (이의 제기)

복구 신청이 거부된 결과에 이의가 있는 경우, 통보일로부터 14일 이내에 고객센터를
통해 재검토를 요청할 수 있다.

### 제12조 (정책의 변경)

이 정책은 콘텐츠 추가·변경에 따라 적용 대상 아이템 목록이 개정될 수 있으며, 개정 시
공식 홈페이지를 통해 사전 공지한다.
